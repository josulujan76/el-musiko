LOGOS LEYENDA - ÁNIMO

Contenido:
- 15 logos correspondientes a las bandas del nivel Leyenda.
- default.png para cualquier logo que falte o no pueda cargarse.
- fuentes.tsv con la procedencia de cada imagen.

Uso:
1. Copiar todos los PNG dentro de JuegoMusico/logos.
2. Mantener exactamente estos nombres de archivo.
3. No copiar fuentes.tsv ni LEEME.txt si no se desean dentro del proyecto.

Formato:
- PNG
- Lienzo de 512 x 256 píxeles
- Fondo transparente cuando el archivo fuente lo permite

Aviso:
Los nombres y logotipos pueden estar protegidos como marcas, aunque ciertas
versiones tipográficas estén disponibles como dominio público. Este paquete
está preparado para probar el prototipo local. Antes de publicar o monetizar
el juego, corresponde revisar permisos y marcas aplicables.
